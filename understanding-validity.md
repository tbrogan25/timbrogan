# Understanding Validity

### What makes a signature valid?

* A signature is valid if the combination of the written signature, printed name, and address can be confidently matched to one and only one registered voter.
* None of the handwritten name or address should clearly conflict with the voter you're matching it to. For example, if the written last name clearly includes a "gg" but the voter's last name doesn't, that's a strong sign it's not a valid match.

### A signature is _valid_ even if...

#### Names

* ...if a nickname is used (e.g., "Mike" for "Michael," "Tony" for "Anthony," etc.), but only if the nickname is intuitive and commonly used. If a signer writes "Joey Smith" but there's only a "Jeremy Smith" at the address, it would be invalid because "Joey" is not a common nickname for "Jeremy."
* ...if initials are used for the first and/or last name, but only if no one else at that address shares those initials
* ...if there are spelling errors (e.g., switched or missing letters in names) but the intent is clear with all other clues matching
* ...if the handwriting is barely legible but the visible letters or clues clearly point to one and only one voter at that address.

#### Addresses

* ...if street suffixes are missing (e.g., “123 Main” instead of “123 Main St”)
* ...if street suffixes are incorrect (e.g., “123 Main Rd” instead of “123 Main St”)
* ...if street names are shortened (e.g., “Wash St” for “Washington St”)
* ...if an apartment number missing or incorrect
* ...if an apartment number is present when it's not present in the database
* ...if the address spans multiple rows (e.g., signer wrote across Row 1 and Row 2)
* ...if no town name is written at the bottom of the sheet
* ...if a signer uses ditto marks to indicate that their address is the same as the above signer's address.

### A signature is _invalid_ if...

#### Names

* ...if it contains illegible writing that cannot be confidently matched to a single voter, even if only one person lives there. Details need to align between the signer and the voter, not just because there's only one voter at the address
* ...if two people at the same address share the same name, and the signer didn’t include anything extra to tell you which one they are, like “Jr.” or “Sr.,” meaning you can’t tell them apart.
  * Some families don't even use name suffixes in the first place, meaning there could be two identically named people at the same address, like a father and son, who only differ based on their middle names. If the signer didn't include their middle initial/name, you can't tell them apart and need to mark it invalid.
* ...if a signer uses a different last name (e.g., maiden or married name), even if it's clearly the same person
* ...if a signer uses their middle name as their first name. There is no way to tell that the signer is actually that voter, as it's common for family members to reuse their middle and first names.

#### Addresses

* ...if the written street number is incorrect, even if their intention was clear
* ...if the street number is missing
* ...if the signer's address is not located in the town handwritten at the bottom of the petition sheet. All signers must live in the town printed
