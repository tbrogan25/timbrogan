# Voter Validator Position

Welcome to Certifi.

You will be responsible for using AI to assist you in handwriting transcription. Using Certifi's web-portal, you'll transcribe handwritten names and addresses to help determine whether a signature is valid based on a match in the voter database. If there's a match, it's valid. If not, it's invalid - and you'll select the reason why.

It's a pretty simple task with a bit of nuance, which we'll get into soon.

#### **Your Role**

* Read a handwritten name and address from a scanned image.
* Visually match or manually transcribe that information into a search box.
* If a match appears in the search results, select it to mark the signature as valid.
* If no match appears, you will choose one of three rejection reasons:
  * **Illegible** – handwriting is so unreadable you cannot even make a genuine search attempt for the name or address.
  * **Failed Match** – name and address are readable enough to make a genuine search attempt for the name or address, but no match appears.

#### Requirements

* A large monitor
* High attention to detail (spelling, formatting)
* Good vision
* Open availability when work goes live (often short bursts of high-volume work)

#### Pay

You will be paid varying numbers of cents per voter that you validate. Your pay is simply determined by the pass you're doing, regardless of whether signatures end up being valid or invalid.

Basic Pass - $0.02 per signature for confirming match, $0.04 per signature for finding error\
Expert Pass - $0.04 per signature for confirming match, $0.07 per signature for finding error\
First Pass - $0.05 per signature

After a little bit of experience, our average validators earn roughly $15/hour.

#### Workload

Work is very unpredictable in our industry. There are certain known "busy seasons" where there are weeks or months of demanding work followed by weeks of no work. You will fit best at Certifi if your schedule is adaptable to this style of work.
