# How to Upload Turn-Ins

The following is a guide on how to upload turn-ins properly.

1. Go to the link: [app.certifiapp.com](https://app.certifiapp.com)
2. Enter your credentials, make sure you select "Client," then log in

<figure><img src=".gitbook/assets/image (141).png" alt=""><figcaption></figcaption></figure>

3. Click the blue "New Turn In" button in the top right

<div data-full-width="true"><figure><img src=".gitbook/assets/image (142).png" alt=""><figcaption></figcaption></figure></div>

4. Input all of the turn-in information, such as:

* Project name
* Coordinator/company name
* Petitioner name
* Turn-in date

<figure><img src=".gitbook/assets/image (144).png" alt=""><figcaption></figcaption></figure>

If you need to create a Project, click "Projects" on the left. Input your project's name, then select "Quick Add" to create it.

<div data-full-width="true"><figure><img src=".gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure></div>

If you need to create a Coordinator, click "Coordinators" on the left. Input the coordinator's first and last name and organization, then select "Quick Add" to create them.

<div data-full-width="true"><figure><img src=".gitbook/assets/image (2) (1) (1) (1).png" alt=""><figcaption></figcaption></figure></div>

If you need to create a Petitioner, click "Petitioners" on the left. Input the petitioner's first and last name, then select "Quick Add" to create them.

<div data-full-width="true"><figure><img src=".gitbook/assets/image (1) (1) (1) (1).png" alt=""><figcaption></figcaption></figure></div>



5. Select files to upload

Make sure you upload a _zipped folder_ of scanned petition images that only contain _.jpg files_

<figure><img src=".gitbook/assets/image (145).png" alt=""><figcaption></figcaption></figure>

Here's how to zip a folder on Windows 10:

* Right click the folder you want to zip

<figure><img src=".gitbook/assets/image (146).png" alt=""><figcaption></figcaption></figure>

* Click "Send to" > "Compressed (zipped) folder"

<figure><img src=".gitbook/assets/image (147).png" alt=""><figcaption></figcaption></figure>

* The zipped folder will be named whatever it was named prior to being zipped, but you can change it now if necessary. If you don't want to change it, press Enter

<figure><img src=".gitbook/assets/image (148).png" alt=""><figcaption></figcaption></figure>

Here's how to zip a folder on Windows 11:

* Right click the folder you want to zip and click "Compress to" > ZIP file"

<figure><img src=".gitbook/assets/image (149).png" alt=""><figcaption></figcaption></figure>

Once your folder is zipped, select it, then click "Open."

<figure><img src=".gitbook/assets/image (150).png" alt=""><figcaption></figcaption></figure>

6. Once you've opened the correct zipped folder, click "Upload" in the bottom right

<figure><img src=".gitbook/assets/image (151).png" alt=""><figcaption></figcaption></figure>

Wait for the upload. This should be fast:

<figure><img src=".gitbook/assets/image (152).png" alt=""><figcaption></figcaption></figure>

7. Once the sheets have uploaded as indicated at the bottom, click the blue "Process Ballot Sheets" button in the top left

<figure><img src=".gitbook/assets/image (153).png" alt=""><figcaption></figcaption></figure>

8. Once you click "Process Ballot Sheets," you can safely close the tab _only when you see the status say **"Preparing."**_ If you click away too soon, the turn-in will be processed infinitely and incur infinite infrastructural charges.

<figure><img src=".gitbook/assets/image (154).png" alt=""><figcaption></figcaption></figure>

You can also safely close the tab when it says _**"PROCESSING."**_

<figure><img src=".gitbook/assets/image (155).png" alt=""><figcaption></figcaption></figure>

The turn-in will process for a few minutes depending on the number of sheets and number of total signatures, as well as if there are any other turn-ins being uploaded & processed.

9. Viewing your turn-in progress

Back on the "Turn-Ins" screen, you can see the newly uploaded turn-ins and some details about them, including:

* Project, Coordinator, Petitioner
* \# of sheets
* \# of total signatures (This metric may initially be off by a few signatures because the AI can read crossed out signatures & may count a signature across two rows as two separate signatures, etc.)
* \# of signatures that need manual validation
* \# of signatures that have been automatically validated
* Processing status, which can be:
  * Processing
  * Completed
  * Idle (bad)
  * Failed

<figure><img src=".gitbook/assets/image (156).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Ignore the "Activate" buttons.&#x20;
{% endhint %}

Lastly, try not to upload duplicate turn-ins as this will incur unnecessary charges as well.

\
Happy uploading!
